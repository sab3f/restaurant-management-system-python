# 🍽️ Restaurant Management System (Python OOP)

A command-line based Restaurant Management System built using Python and Object-Oriented Programming (OOP).  
This project simulates real-world restaurant operations including customer ordering, cart management, menu handling, and admin control of employees and items.

---

## 🚀 Features

### 👤 Customer Features
- View restaurant menu
- Add food items to cart
- View cart with total price
- Pay bill and clear cart

### 👨‍💼 Admin Features
- Add new food items to menu
- Remove items from menu
- Add employees
- View employee list
- Manage restaurant data
